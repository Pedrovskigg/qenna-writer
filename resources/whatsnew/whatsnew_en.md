**• NEW DIALOGUE DETECTOR ENGINE**
Introducing: **Granna**.
Granna is the new dialogue detection engine, written from absolute scratch for the new versions of Qenna.
The old text engine was... problematic. Too many rules, too many mistakes. It failed way too often, let obvious lines slip by and couldn't tell who said most of them.

So, to get rid of the problems, we cleaned house and rebuilt it.
The new engine gets up to 3x more hits and detections than the old one.
And no, I'm not exaggerating.

At the end of this patch note, I'll leave more details about the new engine. How it works, hit rates and all that, in case you're curious. It's really worth the read. It's good to know how it works.

**• Granna: How does it work?**

First we have to talk about the old detector, so the difference makes sense.
The old detector worked like this:
It took each line on its own and looked for a character name after the dash (or after the quotes).

○ Found one name: the line belonged to that character.
○ Found none: it gave up. "Unattributed."
○ Found two: it gave up too. And that happened a lot, because it mixed up the rest of the line with the tag:

Like this:

"Not him," Maria admitted. "But Samantha, yes."

○ It saw "Maria" and "Samantha" and threw in the towel.

"I won't," she said. No name, no speaker.
"Outside?" A line with no tag at all, no speaker.

If the project had a narrator, any line with "I", "said" or "how" went to the narrator, even when it was someone else's.

It only understood dashes and double quotes. « » quotes, common in Italian and French, it didn't even see.

*And now, friends... buckle up.*

**THIS IS HOW GRANNA WORKS:**

It reads the scene from top to bottom, remembering the conversation:

**○ It separates speech from narration.**
"Maria admitted" is the tag; "But Samantha, yes" is speech.
**○ It understands who the subject is.**
In "Clara said", Clara is speaking. In "looked at Clara", she isn't.
**○ It follows the turns.**
If Clara and João are talking, "Outside?" comes right after Clara, so it's João's.
**○ It notices who was addressed.**
In "Thanks, Maria.", Maria isn't the one speaking: it's whoever is talking to her.
**○ It understands "he said" and "she said"**
through each character's gender. **You set it in the new Form of address when creating/editing characters**, or it figures it out from the text.
**○ It recognizes extras.**
"Room 9," the young man said. There is a speaker, but it's no one in your cast, so it doesn't hand the line to the wrong character.
**○ It understands first person**
through the narrator set for the chapter: "No," I replied.
**○ It understands a gesture before the line**
In books with quotes: Oda shrugged. "Fair has nothing to do with it."
**○ It figures out each chapter's language on its own**
And uses that language's rules: dashes, quotes, « », the Spanish raya and the French incise ("— Je pars, dit Marie.").
**○ In screenplays**
It reads the speaker straight from the character block.

**○ And it tells you when it's guessing**
With the name written in the tag, the line is marked as certain. When it deduces from the conversation, the line shows up as "probable", and a right-click confirms or fixes it. What you fix is never undone.

**○ Behind the scenes, saved lines became reliable too**

Edited a line? The old version no longer stays forgotten in the file, counting in the statistics.
Two identical lines ("Yes.") in the same chapter still count as two.
"Not dialogue" removes a line that isn't dialogue for good; before, it came back on its own.
Scan all shows, in the progress bar, every new line, every speaker change and every line that was removed, with where it is and who said it.

**HIT RATES:**
On test chapters in all five languages:
old engine 25% | Granna 93%, reaching 97% with the form of address set on the characters.
By language (Granna): IT 100% · PT-BR 100% · ES 92% · FR 91% · EN 81% (100% with form of address)

The old engine's best rate was 54%, in ES.
Italian it didn't detect at all.
9% in FR.
25% in EN.

No need to drag it out. It's an absurd leap in power.

## Fixes
A few quick fixes to smooth out some rough edges from the last version.
It was a big update, so something slipping through was expected. No drama, here's what got fixed.

**• Auto-update error**
*\\ the path was not specified.*
This error was Qt escaping some quotes. cmd doesn't interpret the character, so running the update failed.
It was fixed in a re-release of 0.18.0. I edited that release with a setup that had the fix. So if you downloaded it later, you probably won't hit the bug.
Fixed.

**• Daily goal percentage stuck at 100%, even if you kept going**
Yep. The new counters are beautiful, but they had a display issue with the goal percentage, which froze once the goal was reached and stopped growing.
Fixed.

**• Theme colors x New display styles**
Some themes' colors could make some content unreadable in the Pensarium's new display styles. Fixed.

**• App tooltip colors**
The manuscript drawer tooltip and many others could turn completely black, with no readable content. Fixed.

**• Counter tweak**
It now animates when it changes size.

**• Crash when switching the gender (M/F) of relationships**
When creating a relationship, if you tried to switch the gender of the options, the program crashed outright.
Fixed.

**• Two-window main menu**
Before, when going to the main menu, Qenna split into two windows, one with the editor and another with the menu.
Now it's just one.

**• Other fixes**
Close, Cancel and the copy/paste menu now show up in the app's language.
Cut-off labels on the territory sheet (in English) and on the glossary chip were fixed.

**• Window colors**
They inherited the Windows color. Fixed. Now Qenna's windows take the Theme's color.

**• Patch Note window**
Aaah, I finally fixed the margin of the patch note window. It should display correctly this time.
