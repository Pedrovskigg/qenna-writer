Source Serif 4 (Google Fonts, SIL OFL 1.1 — see OFL.txt).

These are static instances generated from the official variable fonts
(SourceSerif4[opsz,wght].ttf and SourceSerif4-Italic[opsz,wght].ttf) with
fontTools varLib.instancer at opsz=14: Regular (wght 400), SemiBold (wght 600)
and Italic (wght 400). Names normalized to the single family "Source Serif 4".

Why static: Qenna renders with the FreeType font engine, which does not pick
weights from a variable font and would synthesize a blurry fake bold instead.
