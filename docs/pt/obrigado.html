Antes de instalar

Quando você abrir o instalador, o Windows vai mostrar uma tela azul escrito "O Windows protegeu o computador". Ele não encontrou nada de errado no arquivo — ele só não reconhece quem assinou.

Mais informações→Executar assim mesmo

Essa mensagem aparece pois o instalador não possui certificado de assinatura.

Lembrando: caso tenha dúvidas, o código-fonte do Qenna sempre pode ser lido e acessado aqui.

Carta do criadorQenna Writer

Olá,

sou P.H. Lobato, criador e desenvolvedor do Qenna Writer.

Eu fiz esse programa para o meu próprio uso. O mercado de software desse nicho virou uma coisa… assustadora, financeiramente falando. Assinatura, freemium, paywall. E mesmo depois de testar um monte deles, o mesmo problema aparecia: nenhum servia. Talvez eu fosse exigente demais? É possível. Mas alguma coisa sempre faltava.

Frustrado e cansado de depender de quatro programas diferentes para escrever um livro, comecei a desenvolver o Qenna Writer por conta própria, partindo do absoluto zero.

Sem nenhuma noção de programação, nem de como fazer aquilo funcionar.

Aprendendo com meus erros, quebrando coisas, consertando.

Eu queria uma coisa só: um software de escrita criativa que me desse tudo que eu quisesse ou pudesse precisar. Para sempre.

E quando ele finalmente viu a luz do dia, decidi que seria quase um crime guardar aquilo só para mim.

Então o Qenna hoje é público e gratuito. E sempre será.

Espero que ele dê conta das suas necessidades criativas como deu das minhas. Cada função, cada ferramenta, cada detalhe da interface foi pensado para deixar o processo criativo mais funcional, mais intuitivo e mais divertido.

E, sinceramente? Acho que cheguei onde queria.

Tenho orgulho do que construí, e estou ansioso para ver que boas histórias vão ver a luz do dia através dele.

Aproveite.

Atenciosamente,Guardião das Terras de Qenna
